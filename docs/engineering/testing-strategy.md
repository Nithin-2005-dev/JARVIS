# Testing strategy

The `unittest` suite checks deterministic replay and unique event IDs, all five service identities and scenarios, expected database/downstream fault events, monotonic per-trace times and shared payment identity, rejection of malformed structures, and JSONL parse/validation. Stage 2 also tests JSON arrays and JSONL, CSV, REST against a local HTTP server, simulated live events, malformed JSON, required fields/types, timestamps, severity, UUIDs, UTC normalization, metadata/source preservation, duplicate IDs within/across batches, quarantine isolation, Stage 1 sample ingestion, and a 5,000-row JSONL batch. Tests are local and deterministic; no external services are contacted.
